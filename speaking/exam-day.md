# 시험 전날 · 시험 당일

처음 응시하는 사람은 실력보다 **절차를 몰라서** 흔들린다. 이 문서는 시험장에서 무슨 일이 일어나는지와
전날·당일에 무엇을 할지를 모은다. 훈련 내용은 `speaking/tips.md`, 형식은 `speaking/format.md`.

**확인된 것과 확인 못 한 것을 구분해 적었다.** 확인 못 한 항목은 시험장에서 처음 겪게 되므로,
그런 게 있다는 것만 알고 들어가면 된다.

---

## 1. 준비물과 입실 — 확인됨

| 항목 | 내용 |
|---|---|
| 신분증 | **규정 신분증만** 인정. 학생증·사원증·자격증·사진 부착 신용카드·국제운전면허증·**유효기간 지난 신분증은 불가** |
| 수험표 | 시험 당일 오전에 카카오톡으로 모바일 수험표 발송. 고사장·고사실·좌석번호·입실시간이 적혀 있다 |
| 필기구 | **필요 없다.** 시험장에서 메모지와 필기구를 준다 |
| 입실 | **입실 통제 시각이 지나면 입장 자체가 불가.** 회차별로 다르니 수험표의 시각을 따른다 |

응시료는 팔만 원대다. 신분증 하나로 못 들어가면 그대로 날아간다. **전날 밤에 신분증을 지갑에 넣어 둔다.**

## 2. 시험장에서 — 확인된 것

- **컴퓨터와 헤드셋을 쓰는 CBT 방식이다.** 마이크에 대고 말하면 녹음된다.
- **헤드셋은 시험 내내 쓰고 있는다.**
- **준비 시간에 메모할 수 있다.** 나눠 주는 메모지에 적는다. 다만 **키워드만** 적는다 (`tips.md` §9).
- **여러 사람이 동시에 말한다.** 방음이 잘 된 곳도 있고 칸막이만 있는 곳도 있다.
  옆 사람 목소리가 마이크에 들어오는 환경도 실제로 보고된다.
- **목소리는 평소 톤으로 또박또박.** 소리치지도 속삭이지도 않는다. 다만 주변이 시끄러우면
  묻히지 않을 정도로는 낸다. 구체적인 기준은 **미확인**.
- **답변이 시간 종료로 문장 중간에 끊겨도, 핵심 답을 이미 말했다면 그 자체로 감점되지는 않는다.**
  (한국토익위원회 안내) 반대로 **시간 안에 핵심 내용을 못 끝내면 완성도에서 불리하다.**

## 3. 시험장에서 — 확인 못 한 것

아래는 검색으로 확정하지 못했다. **모른다는 걸 알고 들어가는 것만으로도 당황이 준다.**

- 신분 확인 → 자리 배정 → 헤드셋 착용 → 마이크 음량 테스트의 정확한 순서와 화면 클릭 절차
- 화면 안내가 영어인지 한국어인지
- 남은 시간이 초 단위로 표시되는지, 준비 종료와 답변 종료에 각각 신호음이 있는지
  (준비 시간 뒤 삐 소리로 답변이 시작되고 시간이 끝나면 자동으로 다음 문항으로 넘어간다는 서술은
  있으나 출처 하나뿐이다)
- **답변을 다시 녹음하거나 이전 문항으로 돌아갈 수 있는지**
- 질문을 못 알아들었을 때 다시 들을 수 있는지

**안전한 가정** — 되돌아갈 수 없고 다시 들을 수 없다고 보고 연습한다. 실제로 가능하면 이득이고,
불가능한데 가능하다고 믿고 갔으면 그 문항을 통째로 잃는다.

## 4. 전날 — 새로 외우지 않는다

**전날의 목표는 실력을 만드는 게 아니라 가진 실력을 꺼낼 수 있게 만드는 것이다.**

### 하지 않을 것 넷

1. 새 템플릿을 잔뜩 외운다 — 기존 표현과 섞여 오히려 막힌다
2. 안 쓰던 어려운 단어를 답변에 넣는다
3. 밤늦게까지 모의고사를 반복한다 — 피곤하면 생각과 말이 같이 느려진다
4. 남의 고득점 답변과 계속 비교한다

### 한 시간 루틴

| 시간 | 할 일 |
|---|---|
| 10분 | 기본 표현 복습 — 의견 · 이유 · 예시 · 결과를 각각 한 문장씩 실제로 말한다 |
| 15분 | 사진 묘사 두세 장 — 장소 → 위치 → 사람 → 행동 → 배경 순서만 유지 |
| 15분 | 의견 문제 세 개 — 키워드 넷(opinion · reason · example · result)만 잡고 바로 답한다 |
| 10분 | 오늘 답변 한두 개만 다시 듣기 |
| 10분 | 자주 틀리던 것 확인 — 3인칭 단수 · 과거형 · 관사 · 단수복수 |

모의고사는 **한 세트면 충분하다.** 점수보다 이걸 본다 — 빠르게 시작했나 · 긴 침묵이 있었나 ·
끝까지 이어갔나 · 같은 표현을 반복했나 · 속도가 일정했나 · 이유와 예시가 이어졌나.

### 확정된 문항은 다시 보지 않는다

`my/speaking/templates.md` 에서 **두 번 ○ 로 확정된 문항**은 전날 복습 대상이 아니다 (CLAUDE.md §7).
남은 시간은 아직 △ 인 문항에 쓴다.

## 5. 당일 아침 — 공부가 아니라 워밍업

| 시간 | 할 일 |
|---|---|
| 5분 | 익숙한 영어 문장 소리 내어 읽기 |
| 5분 | 사진 한 장 묘사 |
| 5분 | 익숙한 의견 문제 한두 개 답하기 |

목표는 실력 확인이 아니라 **영어가 입에서 나오는 상태를 깨우는 것**이다.

## 6. 시험 직전 10분 — 다섯 줄만

1. 첫 문장을 빠르게 시작한다
2. 어려운 문장보다 내가 아는 문장을 쓴다
3. 작은 실수를 해도 멈추지 않는다
4. 이유 하나를 구체적으로 설명한다
5. 시간이 있으면 예시나 결과를 추가한다

**막히면** — 답 → 이유 하나 → 예시 하나 → 결과.
**아무 이유도 안 떠오르면** — save time · save money · convenient · gain experience · reduce stress.

## 7. 최종 체크리스트

시험 전에 이것만 확인한다. 전부 완벽할 필요는 없고 대부분 익숙하면 된다.

- [ ] 사진을 보면 위치 표현이 바로 나오는가
- [ ] 의견 문제에서 한쪽을 빠르게 고를 수 있는가
- [ ] 이유를 최소 하나 설명할 수 있는가
- [ ] 쓸 만한 경험 소재가 서너 개 준비되어 있는가
- [ ] Q9 에서 표를 다시 보고 정정하는 문장이 나오는가
- [ ] 막혔을 때 쓸 쉬운 표현이 있는가
- [ ] 실수해도 답변을 끝까지 이어갈 수 있는가
- [ ] 신분증을 챙겼는가

## 8. 시험 뒤

`/toeic debrief` 로 들어간다 (CLAUDE.md §3).

**성적표가 나오기 전에 기억부터 적는다.** 성적표에는 실수가 안 적혀 있고, 시험 직후의 기억이
다음 준비에 더 쓸모 있다.

- 준비 시간이 부족했나 → 첫 문장 자동화가 우선
- 이유가 안 떠올랐나 → 이유 은행을 늘린다
- 문장은 아는데 입으로 안 나왔나 → 말하기 횟수를 늘린다
- 주변 소음에 흔들렸나 → 소음을 두고 연습해 본다

**점수가 목표보다 낮아도 그 회차는 데이터다.** 다음 시험은 복수전이 아니라 **수정본 제출**이다.
지난번에 안 됐던 것 하나를 고쳐서 다시 낸다.
