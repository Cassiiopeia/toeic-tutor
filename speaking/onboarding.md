# 토스가 처음이라면 — 여기부터

**토익스피킹을 한 번도 안 본 사람이 처음 읽는 문서다.** 조수는 `my/profile.md` 의 「토스 경험」이
「없음」이면 진단이나 훈련보다 **이 문서를 먼저 통째로** 안내한다 (CLAUDE.md §3).

오리엔테이션은 문제가 아니므로 「한 번에 하나」 규칙을 적용하지 않는다. 한 번에 다 준다.
읽는 데 5분, 그다음 바로 첫 문항으로 간다.

---

## 1. 무슨 시험인가

- **약 20분, 11문항, 200점 만점.** 컴퓨터 앞에 앉아 헤드셋을 쓰고 **마이크에 대고 말한다.**
- **Speaking 과 Writing 은 다른 시험이다.** Writing 은 8문항 60분짜리 별도 시험이고
  이 레포는 다루지 않는다. 「토스」라고 하면 보통 Speaking 만 가리킨다.
- **녹음이 채점자에게 간다.** 사람이 듣는다. 실시간 대화가 아니다.
- **문항마다 준비 시간과 답변 시간이 따로 있다.** 시간이 끝나면 자동으로 다음 문항으로 넘어간다.
  **되돌아갈 수 없다.**
- 필기구는 안 가져가도 된다. 시험장에서 메모지를 준다. **준비 시간에 메모할 수 있다.**

## 2. OPIc 을 본 적 있다면 — 다른 점부터

많이 다르다. OPIc 감각으로 들어가면 첫 문항부터 어긋난다.

| | OPIc | 토스 |
|---|---|---|
| 난이도 선택 | 있음 (직접 고름) | **없음. 모두 같은 시험** |
| 배경 설문 | 있음 (관심사에서 출제) | **없음** |
| 자기소개 | 첫 문항 고정 | **없음** |
| 롤플레이 | 있음 | **없음** |
| 문항 수 | 12~15개 | **11개 고정** |
| 시간 | 약 40분 | **약 20분** |
| 등급 | NL ~ AL | 0~200점 → NL ~ AH |

**내가 고를 수 있는 게 하나도 없다.** 화면이 주는 대로 순서대로 답하고 끝난다.
그래서 **문항별 뼈대를 알고 가느냐가 점수의 대부분**이다.

## 3. 등급

| 레벨 | 점수 | 통용되는 뜻 |
|---|---|---|
| AH | 200 | |
| AM | 180~190 | |
| **AL** | 160~170 | **대기업 선호선** |
| **IH** | 140~150 | **취업 지원 마지노선** |
| IM | 110~130 | |
| IL | 90~100 | |
| NH | 60~80 | |
| NM / NL | 0~50 | |

점수 경계는 자료마다 조금씩 다르게 적힌다. 이 표는 `speaking/format.md` 의 값이고,
회사 기준은 회사마다 다르니 확정으로 쓰지 않는다.

## 4. 11문항이 이렇게 흐른다

| 문항 | 화면에 뜨는 것 | 해야 할 일 | 준비 | 답변 | 배점 |
|---|---|---|---|---|---|
| Q1-2 | 짧은 영어 지문 | **소리 내어 읽는다** | 45초 | 45초 | 0~3 |
| Q3-4 | 사진 한 장 | **보이는 것을 묘사한다** | 45초 | 30초 | 0~3 |
| Q5-7 | 설문 상황 + 질문 셋 | **바로 답한다** | 3초 | 15·15·30초 | 0~3 |
| Q8-10 | 표·일정표 + 질문 셋 | **표를 보고 답한다** | 표 45초 + 3초 | 15·15·30초 | 0~3 |
| Q11 | 의견 질문 하나 | **입장을 정하고 60초 말한다** | 45초 | 60초 | **0~5** |

위 표는 **한국토익위원회 공식 시험 구성표**의 값이다. 사설 자료가 어긋나면 공식을 따른다.

**공식 표에만 있는 것 셋**

- **Q10 은 질문을 두 번 들려준다.** 나머지 문항은 한 번뿐이다. 한 번에 못 잡아도 포기하지 않는다.
- Q8-10 의 「지문 읽는 시간 45초」는 준비 시간과 별개다. 표를 45초 본 뒤 문항마다 3초가 또 있다.
- **북미 원어민 ETS 전문 채점관이 녹음을 듣고 채점한다.** 기계 채점이 아니다.
  성적은 **시험 후 5일 이내**에 나온다.

**채점 항목은 뒤로 갈수록 늘어난다.**

| 문항 | 보는 것 |
|---|---|
| Q1-2 | 발음 · 억양 · 강세 |
| Q3-4 | 위 + 문법 · 어휘 · 일관성 |
| Q5-7 이후 | 위 + 내용의 관련성 · 완성도 |

## 5. 문항별로 무엇을 하는가 — 최소한의 것

각 문항의 자세한 뼈대는 `speaking/templates/` 에, 실전 요령은 `speaking/tips.md` 에 있다.
여기는 **처음 한 번 읽고 시험장에 들고 갈 최소한**이다.

### Q1-2 지문 읽기

공항 안내 방송, 라디오 광고, 자동응답 안내 같은 40~60단어짜리 글이 뜬다. 그대로 읽는다.
**내용을 만들 필요가 없어서 가장 쉽다.**

- 숫자와 고유명사에 힘을 준다
- 열거는 올리고 올리고 마지막만 내린다 — `A↗, B↗, and C↘`
- 쉼표에서 실제로 멈춘다
- 마지막 단어를 흐리지 않는다
- 모르는 단어에서 멈추지 않는다

이 레포는 소리를 못 들어서 채점하지 않는다. 자습이다 (`speaking/q1-2-read-aloud.md`).

### Q3-4 사진 묘사

사람이 뭔가 하고 있는 일상 사진이 뜬다. 카페, 사무실, 공원, 시장 같은 곳이다.

**장소 → 중심 인물 → 주변 인물 → 배경과 소품 → 전체 분위기** 순서로 말한다.

인물을 말할 때 **위치를 먼저 붙인다.** `In the middle of the picture, a woman is ___ .`
`There is` 로만 문장을 시작하면 나열이 되고 장면이 안 그려진다.

### Q5-7 듣고 답하기

먼저 상황이 뜬다. "어느 기관이 무엇을 조사하는데 설문에 참여하기로 했다" 는 식이다.
그다음 질문 셋이 순서대로 나온다. **준비 시간이 사실상 없다.**

- **Q5·Q6 은 15초.** 짧은 사실 질문이다. **직답 한 문장으로 끝내면 감점이다. 두 문장을 만든다.**
  `답 → 이유 또는 추가 정보`
- **Q7 은 30초.** 선호나 선택을 묻는다. `입장 → 이유 → 예시 → 마무리`

### Q8-10 표 보고 답하기

일정표나 이력서 같은 표를 **45초** 동안 본 뒤 질문 셋에 답한다.

45초 동안 표를 다 외우려 하지 않는다. **어디에 무엇이 있는지만 잡는다** — 제목, 각 열의 뜻,
시간과 날짜 위치, 사람 이름과 장소 위치. **취소선이 그어진 항목과 각주는 꼭 본다.**

- **Q8** 표의 기본 정보를 **그대로 인용**한다
- **Q9 가 이 시험의 함정이다.** 질문자가 **일부러 틀린 정보**를 말한다.
  표와 대조해서 **정정해야 한다.** 그냥 `That's correct` 라고 답하면 그 문항은 날아간다.
  정정은 **틀린 값과 맞는 값을 둘 다** 말해야 끝난다.
- **Q10** 해당하는 항목을 **개수부터 밝히고 빠짐없이** 나열한다

### Q11 의견 말하기

찬반, 둘 중 선택, 장단점, 셋 중 가장 중요한 것 넷 중 하나가 나온다.
**유일한 5점짜리라 배점이 가장 크다.**

**입장 → 이유1 + 설명 → 이유2 + 구체적 예시 → 입장 다시** 로 60초를 채운다.
목표 분량은 130~150단어다.

**첫 문장이 입장 선언이어야 한다.** 습관 진술이나 배경 설명으로 열면 채점자가 방향을 못 잡는다.

## 6. 점수는 여기서 갈린다

어려운 단어에서 갈리지 않는다. **세 곳**이다.

1. **Q9 정정** — 알고 가면 맞고 모르면 틀린다. 단기간에 가장 확실하게 오르는 자리다.
2. **Q11 예시와 분량** — 구체적 예시가 있느냐, 130단어를 채우느냐.
3. **Q10 누락** — 항목을 다 말했느냐.

## 7. 흔한 오해 셋

- **"발음이 원어민 같아야 고득점이다"** — 아니다. 발음·억양·강세만 보는 건 Q1-2 뿐이고,
  Q3 부터는 문법·어휘·내용이 함께 들어온다. 알아들을 수 있게 또렷하면 된다.
- **"많이 말할수록 좋다"** — 아니다. 질문에 답하지 않은 채 분량만 늘리면 내용 관련성에서 깎인다.
  **질문에 먼저 답하고, 남는 시간에 붙인다.**
- **"어려운 표현을 써야 한다"** — 아니다. 안 쓰던 표현을 쓰다 문장이 끊기면 전체가 흔들린다.
  **확실히 말할 수 있는 문장 열 개**가 어렴풋이 아는 백 개보다 낫다.

**말하다 틀렸을 때 `I mean` 을 붙여 고쳐 말하는 것은 감점이 아니다.** 다만 문장을 처음부터
다시 시작하지는 않는다 — 흐름이 더 끊긴다.

## 8. 처음 준비하는 순서

시험까지 남은 기간에 따라 다르지만, 순서는 같다.

| 순서 | 무엇 | 왜 |
|---|---|---|
| 1 | **Q8-10, 특히 Q9 정정** | 몰라서 틀리는 유형. 아는 순간 점수가 된다 |
| 2 | **Q11 뼈대와 분량** | 배점이 가장 크다 |
| 3 | **이유 은행과 소재** | 「할 말이 없다」는 대개 영어가 아니라 소재 문제다 |
| 4 | Q3-4 위치 표현 | 순서만 익히면 안정된다 |
| 5 | Q5-7 두 문장 습관 | 짧지만 자주 틀린다 |
| 6 | Q1-2 읽기 | 자습. 마지막에 몰아서 |

**시험이 일주일 안이면 새 표현을 외우지 않는다.** 이미 아는 것을 꺼낼 수 있게 만든다.
시험 전날과 당일은 `speaking/exam-day.md` 를 따른다.

## 9. 이 레포에서는 이렇게 훈련한다

```
/toeic speaking
```

한 세션의 흐름은 이렇다.

1. 복습 카드부터 (있으면)
2. **문항 하나**를 낸다 — 여러 개를 한꺼번에 주지 않는다
3. 타이핑으로 답한다 — 시간은 직접 재고, 목표 단어 수를 지킨다
4. 내용 · 구조와 분량 · 문법과 어휘 세 잣대로 채점한다 (발음은 못 본다)
5. **걸린 곳을 짚고 고친 답을 통째로 보여준 뒤 다시 쓴다** — 최대 3회
6. ○ 난 답은 `my/speaking/templates.md` 에 내 버전으로 쌓인다. 두 번 ○ 면 확정

**분량이 시간의 대리 지표다.** 소리를 못 들으니 단어 수로 답변 시간을 잰다.

| 답변 시간 | 목표 단어 수 | 부족 기준 |
|---|---|---|
| 15초 | 30~35 | 24 미만 |
| 30초 | 60~75 | 48 미만 |
| 60초 | 130~150 | 104 미만 |
