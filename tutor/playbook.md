# 튜터 플레이북

세션을 열 때 이 파일을 읽고 따른다. `CLAUDE.md` 가 뼈대라면 여기는 **사람에게 검증된 살**이다.
사용자별 로그는 `my/tutor-log.md` 에 쌓인다. 거기서 같은 방식이 두 번 ○ 로 확인되면, 그걸 이 공개
플레이북으로 올리는 건 fork 한 사람이 PR 로 한다.

## 검증됨

- **한 번에 문제 하나 + 힌트 한 줄** — paper-study 논문 세션(2026-09-03)에서 검증, interview-prep 으로
  이식됐다. 여러 개를 한꺼번에 주면 동기가 죽는다. 이 레포는 규칙 2번(한 번에 문제 하나 — 세트는
  모의·진단 모드에서만)으로 반영했다.
- **틀리면 직접 고쳐주고 다시 풀게 하기** — paper-study 에서 검증, interview-prep 의 채점 규칙으로
  이식됐다. 걸린 곳을 짚어주면 다음 답에서 스스로 고친다. 이 레포에서는 RC 유형·함정(T-번호), 토스
  잣대(내용·구조/분량·문법·어휘) 중 무엇이 걸렸는지 짚고 다시 시킨다.
- **낱말 뜻만 풀어주고 내용은 요약하지 않는다** — paper-study 에서 검증, interview-prep 에서 법 용어
  대상으로 이식됐다. 이 사용자는 모르는 용어 앞에서 멈추지 논리 앞에서 멈추지 않는다. 이 레포에서는
  RC 어휘·패러프레이징, 토스 표현이 그 자리다.

## 시도 중

- **유형을 안 밝히고 문제를 낸다** — 유형 판별 자체가 실력이다. 미리 알려주면 신호를 읽지 않고 정답
  패턴만 외운다.
- **정답 + 근거 + 함정 세 잣대로 채점한다** — 찍어서 맞은 문제와 신호를 읽고 맞은 문제를 구분해야
  실전에서 재현된다. 근거·함정을 못 대면 정답이어도 △.
- **복습 카드를 같은 문제가 아니라 변형 문제로 낸다** — 문제 자체를 외우면 카드가 무력화된다. 같은
  유형·같은 함정을 새 지문에 심어야 재발 여부를 실제로 잰다.
- **자기 진술보다 성적표 항목값을 믿는다** — "파트는 고루 틀리는 것 같다" 는 진술과 달리, 성적표
  ABILITIES MEASURED 는 평균 아래 항목을 하나로 특정해 줬다(RC 370, 문법만 평균 -7, 나머지 넷은 +3~+29).
  점수대 처방표를 따랐다면 이미 상위권인 Part 7 을 팠을 것이다. 학습자는 자기 약점을 잘못 지목한다 —
  측정값이 있으면 측정값이 이긴다. `rc/prescriptions.md` 「항목별 처방」으로 반영했다.
- **조수가 읽어낸 수치는 사용자 확인을 받는다** — 성적표 PDF 의 한 칸이 워터마크에 가려 있었다.
  좌표로 복원한 값을 확정처럼 쓰지 않고 그 칸을 지목해 되물었다. 추측값 하나가 처방 전체를 틀어놓는다.
  CLAUDE.md §3.2 로 반영했다.
- **약점 유형 60% · 무작위 40% 로 문제를 고른다** — 약점만 파면 실전 분포와 멀어지고, 무작위만
  돌리면 약점이 안 좁혀진다.
- **오답 이유를 사용자가 자기 말로 쓰게 한다** — 조수가 대신 채우면 패턴을 스스로 못 잡는다. 오답
  노트가 실전에서 꺼낼 재료가 되려면 본인 문장이어야 한다.
- **토스 소재 뱅크를 미리 캐 둔다** — "할 말이 없다" 는 대개 소재가 없어서지 영어를 못해서가
  아니다. 소재를 먼저 확보하면 구조·문법에 집중할 수 있다.
- **단어 수를 시간 기준으로 쓴다 (예: 30초 = 60~75단어)** — 타이핑이라 조수가 소리를 못 듣는다.
  시간 대신 단어 수로 분량을 재는 게 유일한 대리 지표다.
